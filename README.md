# 🍕 Página de Vendas DEMO — Pizzaria com Chatbot Embutido

Uma landing page moderna, responsiva e de alta qualidade visual desenvolvida para simular a experiência de um cardápio digital de pizzaria integrado a um assistente virtual (chatbot) automatizado.

---

## 🎯 Objetivo do Projeto
Este repositório serve como um ambiente de demonstração técnica para portfólio. O objetivo principal é demonstrar a união de um design visual focado na experiência do usuário (UI/UX) com uma lógica funcional de atendimento automatizado via chat, simulando a montagem de um pedido do início ao fim (sem conversões reais ou banco de dados).

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias nativas para garantir excelente performance e código limpo:

* **HTML5** — Estruturação semântica, foco em acessibilidade e boas práticas.
* **CSS3** — Estilização moderna, uso de layouts flexíveis (Flexbox/Grid), design responsivo e animações fluidas.
* **JavaScript (Vanilla)** — Lógica para controle dos estados do chatbot, respostas temporizadas e manipulação dinâmica de mensagens no DOM.

---

## 📋 Funcionalidades em Destaque

* 🤖 **Fluxo de Atendimento Automatizado:** Chat interativo com comandos clicáveis de sabores, bordas e tamanhos de pizza.
* 📱 **Design Responsivo:** Interface perfeitamente otimizada para telas de smartphones, tablets e computadores.
* 💬 **Feedback de Digitação:** Animação realista que simula o tempo de resposta do atendente virtual.
* 🧾 **Resumo de Pedido Visual:** Geração automática de um recibo descritivo detalhado com o valor fictício ao término da simulação.

## 🔧 Como Executar o Projeto Localmente

Para baixar os arquivos e testar a aplicação na sua máquina, siga os passos abaixo:

1. **Clone este repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd pagina-de-venda-pizzaria
   ```

3. **Abra a aplicação:**
   * Dê um duplo clique no arquivo `index.html` diretamente em seu navegador ou utilize a extensão *Live Server* no VS Code.
